# E-Commerce Purchase Prediction: End-to-End ML Pipeline & API

An end-to-end machine learning system that predicts online shopping purchase intention from session-level behavioral data, featuring model benchmarking, threshold calibration, FastAPI inference serving, and a lightweight web interface.
